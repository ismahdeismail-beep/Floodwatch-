# ADR-004: MapLibre GL as the Map Rendering Engine

**Status:** Accepted

## Context

The public web app, government dashboard, and (indirectly) the mobile app need
interactive map rendering for flood risk layers, gauge locations, and alert
geographies. Map providers vary in cost, licensing, and key requirements for
development.

## Decision

- Use **MapLibre GL JS** (via `react-map-gl/maplibre` v7) for the web apps.
- Default to the keyless demo style (`https://demotiles.maplibre.org/style.json`)
  for development; production uses a Maptiler/self-hosted style keyed through
  `NEXT_PUBLIC_MAP_STYLE` / `NEXT_PUBLIC_MAPTILER_KEY`.
- Mobile uses **react-native-maps** (native rendering) as a separate, appropriate
  choice for Expo.

## Consequences

- Open-source, no per-tile fees, full vector-tile control, and vector layer styling
  (risk polygons, heatmaps) support out of the box.
- Development requires zero API keys, lowering onboarding friction.
- Some premium styling features present in commercial SDKs are unavailable;
  acceptable for the platform's requirements.
